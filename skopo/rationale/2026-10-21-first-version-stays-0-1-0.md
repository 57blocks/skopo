A 0.2.0 draft fixed "what an independent implementer would trip over before the specification is
made public": a table row's text is built from its cells, so re-aligning columns or moving rows no
longer changes it; a translation is the one view a skopository stores, "because a translation, like
its source, is read and accepted by people"; the lock records accepted text and leaves who accepted
it and when to version control; rationale records name code by file, symbol or commit, "since lines
move"; the dropped check's name stays unused "so that check names keep their meaning across
versions"; and the leak check stays a warning because placement is judged.

That draft was then folded back: Skopo "has not been published, so its first version stays 0.1.0"
and stays a draft. The findings of recovering this skopository from the repository itself came in with it. A checker may stop after errors that
make later findings meaningless, and says so. The ban on secrets and personal data is a judged
requirement. A table stem binds its rows. Text in a code span is quoted, so a skopository can quote
its own syntax. Bindings may be translated, and translations are checked like every statement file.
A generator writes no lock, because "what a generator writes is a proposal" until people accept it.
