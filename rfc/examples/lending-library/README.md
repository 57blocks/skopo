# Lendbox: the skopository

Intent documentation for Lendbox, the lending service of a volunteer-run neighbourhood library. It
follows the Skopo Specification 0.1.0 (a draft) and is the example in its appendix C.

Start with [`spec/lending/charter.md`](spec/lending/charter.md). The spec says what must be true of
lending whatever runs it; the product binding says what members see; the tech binding says how the
service is built. Each statement ends with its ID; only a bold **must**, **must not** or **may**
carries force.

Not here: plans and open questions (the library's tracker), how to run the service (its README).
