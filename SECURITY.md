# Security

Please do not report security problems in public issues. Use GitHub's private vulnerability
reporting: the **Security** tab of this repository, then **Report a vulnerability**.

What counts here:

- the reference tools or the plugin writing or running anything they should not: changing files
  outside the skopository they write, acting on instructions found in the code or documents they
  read, or leaking what they read;
- the whitepaper page rendering content it should not;
- anything in this repository that should not be public.

A recovery reads code and may find weaknesses in the system it reads. Those findings belong to the
system's owners. The plugin keeps them out of the skopository and reports them only to the person
running it; please do not post them here either.
